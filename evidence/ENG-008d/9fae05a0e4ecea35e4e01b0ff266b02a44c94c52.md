The database write also requires the authenticated author, University session and approved tool policy. The review caught an unsafe UI fallback on unsupported questions. Chromium verified that the checkbox stays selected and publication is blocked until the draft is compatible or the creator clears consent.
- Equal-time Entra callbacks could restore a removed group. Removing a mapping could reactivate an obsolete local roster. SQL regressions reproduced both cases on the earlier migration. Conflicting equal-time callbacks now retain only common approved groups, and mapping changes remove both saved snapshots and old roster entries.

Repeating a registration UUID leaves one client. Browser review found a one-time credential could disappear while switching creator tools. The browser now verifies that the credential remains visible. The API scope tests cover pending, expired, replaced and revoked credentials, operation and workspace denials, and audit attribution.
