# Synthetic optional-mode integration

Run against the installed Registry and research migrations and the real PostgreSQL/Chromium development stack. The default survey stays open. A test distribution can have a Registry eligibility capability or a versioned consent notice. Simultaneous restrictions on one publication are refused atomically. Explicit open eligibility remains compatible with consent.

- A mixed policy request receives a redacted validation failure and leaves the draft and version history intact. The same draft can subsequently publish a valid single mode.
- Runtime access to a combined or inconsistent policy fails closed. Direct application-role publication cannot attach consent to a Registry-gated version.
- Installed Registry or consent versions may not start Live Poll or Game Show. Keep all normal, invalid-proof, consent-decline, provider outage, session, migration and browser workflow coverage.
