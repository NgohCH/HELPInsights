## Review and recovery

The integration owner independently reviewed the SQL and API for this verified isolated source and found no blocker to the synthetic draft. The notice is distribution/version-bound and write-at-publication under workspace RLS. The ordinary response helper cannot insert a response for a gated version without the private transaction permit. Rollback and idempotency protect the event count. The separate event stores no timestamp or response pointer.

The test system trusts the API's explicit affirmative request and its browser controls. Real consent needs independently approved presentation and proof semantics. Privileged administrators can disable triggers or write outside the application, and an uncontrolled bulk restore can bypass the runtime guard. A real restore requires consent/response reconciliation and governance sign-off before serving recovered data. PostgreSQL MVCC and WAL retain transaction metadata that can correlate anonymous events and answers.

Consent notice and opt-in records use distribution-version foreign keys and cascade when that distribution is removed. Full research retention, backup reconciliation, and withdrawal remain open. Privileged transaction metadata or small cohorts can still support correlation even when event timestamps and identifiers are absent. A real consent system needs approved wording, governance, and its own privacy review. Preserve migration history and use a forward fix for rollback. The predecessor uses a different migration ledger.

No real identities, sensitive answers, research assignment, provider calls, pushes, merges or production actions were used. Research assignment and reproducibility, governance and retention, withdrawal, longitudinal linkage, psychometric scoring, research exports, and production activation remain open. Cumulative integration must prevent simultaneous synthetic Registry and consent options and must exclude consent-marked snapshots at Live Poll creation. Run tests on the combined candidate before making a broader claim.
