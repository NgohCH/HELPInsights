## Scope and test criteria

ENG-008a is the first curated-template slice of ENG-008 and WP-050. It requires ENG-003 sessions/workspace roles and ENG-004 canonical survey drafts. Owned components include the authenticated template API, creator controls and its tests. The existing survey service transaction and workspace RLS are reused. The OpenAPI contract records list, preview and clone. No migration or role grant changed.

- List a global original Event feedback starter and show its canonical question and options in a read-only preview. Confirm an empty workspace still has zero survey rows after preview.
- Copy a specific revision as an owner/editor to create a separate anonymous draft with the workspace retention policy and no published version or public link. Edit the first copy, create another, and compare the second copy and preview to the original.

## Review and recovery

The integration owner reviewed this exact source and found no blocker. The review examined the session and owner/editor restriction, workspace policy and RLS, revision pinning, canonical definition reuse, and the single transaction with the affected-row guard. The test challenge originally observed an erroneous 201 when the initial update affected no rows. The transaction now checks the affected count and rolls back; the regression makes that failure visible as 503 without an empty copied draft. A caller retrying after an ambiguous network result can create another draft, as each successful POST creates a new independent copy. Keyboard activation and mobile rendering were exercised in Chromium. Sequential focus traversal and screen-reader behavior were outside that check.

Rollback consists of removing the new application routes and controls without rolling back the database. Already created drafts remain ordinary survey drafts. When integrating with the separate saved-draft preview slice, initialize that preview from the clone response so it is available immediately.
