  labels. It held the synthetic export table, observed the single worker's
  checked-out PostgreSQL connection blocked on the relation, and terminated
  that verified worker backend. The test released its transaction lock
  and observed the worker recover.
- The worker container's start time and restart count were unchanged.
  Direct SQL returned `completed:0:true` for the expected job status,
  attempt count and archive existence. The incident pair was recorded after
  a polling transaction committed.
- The operator read `database/detected/advisory` and
  `database/recovered/information` with one shared episode ID and ordered

  no actor ID. The API had only fixed values, timestamps and opaque IDs.

  The worker had no direct incident-table select or insert grant.

## Independent review, retry bounds and remaining scope

The integration reviewer examined fixed scope, grants, episode
idempotency and the committed-poll recovery prerequisite. The review
led to explicit Public and application denial and duplicate checks
after later healthy cycles. A surviving worker retries the same episode
if the database write acknowledgement fails, and uniqueness handles
the ambiguous commit. An unclassified transport failure, including a
driver rejection without a usable error code, may leave no episode.
The episode is in memory until the database recovers, so a worker exit
can lose an uncommitted observation.

The test configuration opts in. The default runtime leaves recording
disabled. Each failed pending cycle has capped backoff and shutdown
cancels waiting. There is no total reconnect-attempt limit for a prolonged
outage. Durable outage buffering, escalation and notice routing remain
open. No process was restarted to remediate the fixture fault, and there
was no shared or production fault or outbound delivery.

The previous runtime compares exact migration history, so an approved
rollback needs a compatible build or a coordinated restore. Preserve
past incident rows and attribution. The standalone migration number
will require reconciliation during cumulative integration.
