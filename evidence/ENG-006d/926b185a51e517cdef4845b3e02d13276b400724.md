## Challenge and limits

The integration owner independently reviewed the exact source. The existing creator save, preview and publish calls retain privacy and retention controls. Templates and NPS remain in simple creation. Publication compares the optional ETag under the same transaction and row lock that snapshot the draft, so a concurrent change cannot slip between the comparison and write. The race test detects a missing precondition by observing an unexpected public link or any version/distribution row. Challenge remaining is repeated valid publication with the same revision and explicit resolution of collaborator changes.

No migrations or new privacy modes are involved. Other purpose profiles, a formal readiness report, multipage authoring, resumable wizard state, explicit reloading of another editor's revision, invited and SSO distribution, expert switching, screen-reader and mobile usability evaluation, and production approval remain open. The existing headerless API remains available. HTTP retries may still produce another immutable version if reissuing a valid publish request with the same draft revision. Source rollback removes the UI and optional precondition while leaving already-published canonical definitions intact.
