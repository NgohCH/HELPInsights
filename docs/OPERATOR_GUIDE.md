# Operator guide — required final deliverable

This is an initial outline to be completed against the running product. Do not call UI actions working before implementation.

## Everyday operation

- Check operational overview: live/ready, DB connectivity, queue lag, disk capacity, backup age and last restore verification.
- Review Action Centre: critical alerts, assigned approvals, recovered events, pending disposal and credential expiry.
- Monitor Project Listen submission health and case handoff; never expose anonymous response identifiers to operational tickets.
- Manage organisations, workspace administrators, survey policy defaults and permitted retention windows.
- Respond to reported issues using runbooks; note incident severity, owner, approval and evidence.

## Incident action notice contract

Every notice includes type, severity, scope, observed symptom, first/last seen, automatic actions, verification status, recommended next action, assigned owner, due/escalation state and audit reference. Deduplicate noisy symptoms; only alert for meaningful changes.

## User-facing guidance

Provide task-oriented walkthroughs for create/preview/publish, invitation distribution, mobile responses, reports and exports, retention expiry, opening JASP exports and permissions. Keep language plain, concise, accessible and British-spelled. Include diagrams/screenshots from the actual final interface.
